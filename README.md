# Fast Subtitle V2

Versi ini memakai API Deepgram yang dimasukkan langsung saat aplikasi dibuka.

Tidak perlu GitHub Secret.

## Build
1. Upload semua isi project ke GitHub.
2. Buka Actions.
3. Jalankan `Build Fast Subtitle V2 APK`.
4. Download artifact `FastSubtitle-V2-APK`.
5. Install APK.
6. Buka aplikasi lalu masukkan API Key Deepgram pada kolom `API Deepgram`.
